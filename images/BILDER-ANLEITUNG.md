# Bilder für das Portfolio

Alle Bildpfade sind bereits im HTML eingebunden. Lege die Dateien einfach in diesem
`images/`-Ordner ab – keine Anpassung im Code nötig, solange du die Dateinamen beibehältst.

| Dateiname       | Wo eingesetzt             | Empfohlene Größe / Format              | Hinweise                                       |
|-----------------|---------------------------|----------------------------------------|------------------------------------------------|
| `hero.jpg`      | Vollbild-Hintergrund      | ≥ 2000 × 1300 px, JPG (< 500 KB)      | Möglichst helles, ruhiges Motiv (Stadtbild,    |
|                 | (Landing Page)            |                                        | Natur, abstraktes Muster). Das Bild wird mit   |
|                 |                           |                                        | einem Dunkel-Overlay überlagert.               |
| `portrait.jpg`  | Kleines Rundbild in der   | 200 × 200 px, JPG oder WebP            | Quadratisches Crop empfehlenswert, da das Bild |
|                 | "Über mich"-Kachel        |                                        | kreisförmig angezeigt wird.                    |
| `project1.jpg`  | Kachel "CRM-Migration"    | 800 × 500 px, JPG oder WebP (< 150 KB)| Büro-/Tech-Motiv passend zum Inhalt.           |
| `project2.jpg`  | Kachel "Sales-Playbook"   | 800 × 500 px, JPG oder WebP (< 150 KB)| Whiteboard, Meeting, Präsentation o.Ä.         |
| `project3.jpg`  | Kachel "ERP Maschinenbau" | 800 × 500 px, JPG oder WebP (< 150 KB)| Industrie-/Technikumgebung o.Ä.                |

**Tipp:** Kostenlose, lizenzfreie Fotos findest du auf [Unsplash](https://unsplash.com)
oder [Pexels](https://pexels.com). Für Projektbilder reichen auch Screenshots oder
Diagramme.

Bis die echten Bilder eingefügt sind, zeigt die Seite einen blauen Farbverlauf als
Fallback – die Seite ist also auch ohne Bilder funktionsfähig.
